# Diabetes Prediction - Logistic Regression

This project predicts diabetes risk using the Pima Indians Diabetes dataset. It demonstrates an end-to-end machine learning workflow that includes data cleaning, exploratory analysis, imbalance handling, and model comparison to support clinical risk prediction.

## Objective
To build a robust classification model capable of predicting the onset of diabetes based on diagnostic measures.

## Key Features
- **Data Preprocessing**: Handling missing values, scaling features.
- **Exploratory Data Analysis**: Visualizing correlations and feature distributions.
- **Handling Imbalance**: Using SMOTE to balance the target class.
- **Modeling**: Training and comparing various models like Logistic Regression, Random Forest, and Decision Trees.

## Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-Learn
- Imbalanced-Learn (SMOTE)
